# Keepframe

Patches MP4/MOV headers on your phone for higher-quality TikTok uploads. Everything runs in the browser; videos are never uploaded.

## Install (Android)
1. Open this site's GitHub Pages address in Chrome.
2. Tap ⋮, then **Install app** (or **Add to Home screen**).
3. Share a video from your gallery or CapCut and pick **Keepframe**. It also works offline.

On iPhone: open it in Safari, tap Share, then **Add to Home Screen** (sharing into the app isn't supported on iOS).

## What it does
- **Passthrough**: the Editing News patcher method, as published open source by buwryme.
- **Density**: NoBlur's frame-density inflation.
- **FPS**: the 120fps-method timing patch for 60/120 fps clips.
- Optional on-device H.264 re-encode (WebCodecs), batch patching, remembered settings.

## Updating
Replace the files with a new build. `sw.js` carries a new version string, so the installed app picks up the update on its next launch.
